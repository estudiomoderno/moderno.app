# Protección de datos y archivos

Antes de modificar almacenamiento o esquema:

1. Verificar por separado copias recuperables de base de datos y archivos.
2. Definir frecuencia y retención adecuadas para el servicio.
3. Probar migraciones y recuperación en un entorno aislado.
4. Mantener compatibilidad con sesiones que usen versiones anteriores.
5. Registrar el resultado de las verificaciones en documentación privada.

No guardar en este repositorio público copias de datos, archivos de clientes, credenciales ni informes operativos internos.

Referencia: https://supabase.com/docs/guides/platform/backups
